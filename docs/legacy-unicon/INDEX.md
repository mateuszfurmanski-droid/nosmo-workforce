## Wall Scanner note

The recovered historical HUD/visor material references Wall Scanner and Sensor Fusion as future work, but no completed standalone Wall Scanner specification was found in the canonical master set. Current Wall Scanner documentation is therefore a new NOSMO R&D track based on the preserved concept, not an invented reconstruction of a missing historical document.
