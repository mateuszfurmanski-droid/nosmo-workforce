## 2. Project proposition

### Working title

**EXO-01 — Passive Human Augmentation Platform for Heavy Construction and Industrial Tool Handling**

### Problem

Construction and heavy industrial workers repeatedly handle tools and loads that create high physical strain, fatigue, ergonomic risk and reduced productivity.

Current construction exoskeleton products are generally:
- upper-body only;
- task-specific;
- not full-body load-transfer systems;
- not designed around modular heavy-tool support;
- not designed around carrying the tool power source on the frame.

### Proposed breakthrough

Develop a modular passive full-body augmentation architecture designed specifically for heavy construction and industrial work.

Core research areas:

1. **Passive full-body load transfer**
   - torso-to-hip-to-leg load path;
   - anthropometric adjustability;
   - human mobility preservation.

2. **Heavy-tool mechanical support**
   - articulated passive support arm;
   - tool mass transferred into the exoskeleton structure;
   - worker retains direct positioning/control.

3. **Frame-mounted tool power**
   - battery / power modules carried by the exoskeleton;
   - power routing integrated through the frame;
   - reduced trailing-cable dependency.

4. **Modular construction tool interface**
   - interchangeable support architecture;
   - generic interface suitable for multiple tool classes;
   - first target: heavy drilling / concrete fixing.

5. **Vibration and shock management**
   - study of how percussive tool loads propagate through the exoskeleton;
   - isolation architecture to avoid transferring harmful vibration into the worker.

6. **Human factors and biomechanical validation**
   - EMG;
   - motion capture;
   - force / load analysis;
   - fatigue and comfort testing;
   - operator diversity and fit.

## 3. TRL strategy

The existing Morph platform must be treated as **background IP / background technology** owned by Andrea's existing startup.

Do not claim that the mature Morph system itself is TRL 3-4 if evidence shows it is higher.

The Horizon project should instead define genuinely new construction-specific research components that are currently at or below TRL 4, for example:

- construction heavy-tool support architecture;
- construction-specific load-transfer geometry;
- vibration isolation;
- frame-mounted tool-power integration;
- modular heavy-tool interface;
- construction PPE / movement compatibility;
- combined full-body + tool-support interaction model.

Target outcome should remain consistent with the call's early-stage breakthrough-research character.

Formal TRL framing must be confirmed with grant specialists before submission.
